# Kit Motion (animação)

Conteúdo copiado do pacote npm `motion-ai@14.2.0` ("Motion AI Kit", Matt Perry / motion.dev,
https://github.com/motiondivision/ai-kit), licença **MIT**. Fixado nesta versão de propósito:
o Universe instala estes arquivos localmente, sem executar código de terceiros.

- `skills/motion/`: a skill (melhores práticas de animação, busca na documentação, molas CSS, auditoria).
- `agents/motion-reviewer.md`: subagente que audita animações de um projeto.
- Servidor MCP aberto do Motion: `https://mcp.motion.dev` (o `plus` exige login Motion+ e não é instalado).

Para atualizar: `npm pack motion-ai@<versão>`, copie `content/skills` e `content/agents` e revise o diff.
